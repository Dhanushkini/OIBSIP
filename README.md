# Data Analytics & Machine Learning Internship Portfolio

Welcome to my Data Analytics portfolio! This repository contains my completed tasks for the **Oasis Infobyte Data Analytics Internship**. It showcases an end-to-end data analytics workflow—from cleaning messy operational datasets to performing deep Exploratory Data Analysis (EDA) and building predictive machine learning models.

## 🛠️ Tech Stack & Skills Demonstrated

* **Languages & Environments:** Python 3, Jupyter Notebooks
* **Data Processing & Cleaning:** `pandas`, `numpy`
* **Data Visualization:** `matplotlib`, `seaborn`
* **Machine Learning & Modeling:** `scikit-learn` (Regression, Classification, Cross-Validation, Feature Importance)
* **Analytical Skills:** Descriptive Statistics, Demographic Segmentation, Trend Identification, Business Strategy Translation
